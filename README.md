# スマートフォン購入検討プロジェクト

Android 1台 + iPhone 1台を予算15万円で購入するための検討記録。

**Claude Code と対話しながら、要件整理 → 調査 → 機種選定 → 購入まで進めた全過程の記録**です。
価格調査の出典、候補を落とした理由、途中で前提が覆って方針転換した経緯まで残しています。

## 要件（出発点）

| | 用途 | 条件 |
|---|---|---|
| **Android** | 普段遣い（液晶が割れて買い替え） | **老眼のため大画面必須** / FeliCa / IP68 / ゲームしない |
| **iPhone** | 開発検証用（Firebase App Distribution 配布のネイティブアプリ） | Wi-Fi中心 / povoで5Gテスト → SIMフリー必須 |
| **予算** | 合計15万円 | 中古も可 |

## 結果

**合計 123,240円**で2台購入（予算内）。

- **Xiaomi 15T Pro**（6.83型 / 3200nits / FeliCa / IP68）— 中古 74,800円
- **iPhone 13**（Face ID / ノッチ / 国内版SIMフリー）— 中古 47,800円

## 読みどころ

途中で**2回、前提が覆って方針転換**しています。

1. **Xiaomi の「79,800円」は乗り換えキャンペーン価格だった** — SIMフリー単体は109,800円。
   → 新品から中古Bランク（74,800円）に切り替え（[06-decision-log.md](06-decision-log.md) D10）
2. **iPhone SE3 を外した理由が当初の説明と違っていた** — 「OS寿命が短い」と述べたが、
   SE3 と iPhone 13 は同じ A15 Bionic でサポート時期はほぼ同じ。
   実際の理由は**検証カバー範囲**（Face ID・ノッチ・セーフエリアが再現できない）
   （[06-decision-log.md](06-decision-log.md) D8）

また、**WebSearch の要約が誤った価格を返した事例**とその検出・訂正の記録も残しています
（[06-decision-log.md](06-decision-log.md) 訂正記録 C1・C2）。
